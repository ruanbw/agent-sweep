# AgentSweep — Design System

> 一份语义化设计规范。用于生成新界面、评审改动、以及实现 `prototype/`。
> 关键词：安静、可信、可逆、键盘优先、macOS 原生质感。

---

## 1. 视觉主题与气氛

**The Quiet Workbench** — 一张安静的清理台。

暖纸色的画布、墨色的字、唯一的一抹石板蓝。界面不表演，不发光，不漂浮；
所有表面靠 1px 发丝线分隔，阴影只留给真正浮起来的层（菜单、抽屉、对话框）。
密度是「日常工具」而不是「机场塔台」：表格行有呼吸，但一屏仍能看见 12 条会话。

- **Density** 6 / 10 — 与 macOS 原生工具（Finder、Activity Monitor）同一档
- **Variance** 3 / 10 — 结构稳定，三栏对齐；变化来自排版与状态，不来自扭曲布局
- **Motion** 4 / 10 — 有反馈、无表演；只动 transform / opacity
- **Texture** 2 / 10 — 只在窗口外的桌面留一点纸纹；应用内容保持干净

设计策略是 **升级而不是重做**：保留现有产品的暖纸底、石板蓝、三栏工作区，
把层级、状态、可逆性、键盘路径和细节补齐。

### 设计原则

1. **可逆优先。** 清理是危险操作。所有破坏性动作先解释后果，再给撤销，再给回执。
2. **诚实计数。** 「移入废纸篓」不释放空间，「真实释放」单独计算；两者永远分开说。
3. **浏览不是选择。** 点击一行只是「看」，勾选才是「选」；减少误清空。
4. **就地反馈。** 进度、结果、错误都出现在动作发生的地方，不用弹窗打断浏览。
5. **键盘是一等公民。** 每个高频动作都有快捷键，焦点永远可见。
6. **系统原生。** 继承 macOS 的字、色、滚动、焦点与窗口行为；不自造一套平台。

深色模式不是反相：品牌图标使用各自的 `dark` 色值，阴影加深并用暖中性色，
选中态提高透明度而不是提高饱和度。

### 2.3 用色规则

- **一个强调色。** 石板蓝只用于「当前/选中/可交互/焦点」，不用于装饰。
- 警告黄、危险红、成功绿是**语义色**，只在对应状态出现，不做品牌色。
- 大面积表面永远中性；彩色只出现在小面积（图标、勾选、徽标、状态点）。
- 阴影必须带背景色相：浅色用 `rgba(38,34,26,…)`，深色用 `rgba(0,0,0,…)`。
- 禁止：纯黑 `#000`、紫蓝渐变、霓虹发光、饱和度 > 80% 的色块。

## 3. 字体

```css
--font-ui: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
  "PingFang SC", "Hiragino Sans GB", "Helvetica Neue", system-ui, sans-serif;
--font-mono: ui-monospace, "SF Mono", "JetBrains Mono", "Cascadia Mono", Menlo, monospace;
```

系统字体不是妥协：这是 macOS 应用，SF Pro + PingFang SC 的中英混排质量高于任何 Web 字体，
并且离线可用、零加载。**不引入任何网络字体。**

### 3.1 字号阶梯

| Token | 字重 / 行高 / 字距 | 用途 |
|---|---|---|
| `display` | 600 · 21/27 · -0.02em | 抽屉标题、对话框标题 |
| `title` | 600 · 16/22 · -0.01em | 面板标题、详情标题（小一号） |
| `strong` | 590 · 13.5/19 · 0 | 表格标题、按钮、强调正文 |
| `body` | 400 · 13/19 · 0 | 正文、摘要 |
| `small` | 400 · 12/17 · 0 | 次级说明、表格摘要、元信息 |
| `micro` | 560 · 11/15 · +0.06em | 分组标签（大写仅用于英文短标签） |
| `path` | 400 · 11.5/16 · 0 | 路径、ID、快捷键说明，等宽 |
| `stat` | 600 · 17/22 · -0.01em | 统计数字，等宽数字 |

规则：
- 所有数字启用 `font-variant-numeric: tabular-nums`，体积、消息数、时间不跳动。
- 中文标题 `letter-spacing: 0`，不做负字距；英文大标题才用负字距。
- 正文最大 65ch；详情面板按容器宽度自然换行，不用固定宽度硬截断。
- 标题使用 `text-wrap: balance`，摘要使用 `text-wrap: pretty`。
- 不用全大写中文；英文小标签可用 `micro`。

## 4. 空间、形状、层级

### 4.1 间距（4pt 基）

`4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 56`

- 内容区内边距：20px（列表）/ 20px（详情）/ 16px（侧栏）
- 顶部栏高度：56px；状态栏：44px；表头：36px
- 行高：舒适 56px，紧凑 42px；对话框内边距 24px；抽屉 24px
- 分组之间 24–32px，组内 8–12px

### 4.2 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--r-window` | 14px | 原型窗口（生产环境由系统窗口提供） |
| `--r-sheet` | 12px | 抽屉、对话框、命令面板 |
| `--r-card` | 9px | 卡片、输入框、菜单 |
| `--r-control` | 7px | 按钮、分段控件、复选框 |
| `--r-kbd` | 4px | 快捷键帽 |
| `--r-pill` | 999px | **只用于状态徽标**，不用于按钮或容器 |

### 4.3 阴影与描边

- 主表面 **不阴影**，只有 1px `--line`。
- 浮层（抽屉/对话框/菜单/命令面板）使用：
  - 浅色 `0 24px 64px -28px rgba(38,34,26,.28), 0 2px 8px rgba(38,34,26,.06)`
  - 深色 `0 28px 72px -24px rgba(0,0,0,.65), 0 2px 8px rgba(0,0,0,.35)`
- 遮罩：浅色 `rgba(28,30,34,.26)`；深色 `rgba(0,0,0,.55)`。仅浮层用 `backdrop-filter: blur(2px)`。
- 阴影方向统一为自上而下；不允许内阴影造成「凹陷卡片」错觉（除输入框聚焦）。

### 4.4 z-index 层级

`0` 内容 → `10` 顶栏/状态栏 → `20` 浮层 → `30` 抽屉/对话框 → `40` 命令面板 → `50` 通知 → `60` 原型控制台（仅原型）。

## 5. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ titlebar（原型模拟；生产为系统窗口栏）                          │
├──────────────────────────────────────────────────────────────┤
│ topbar 56  [品牌]        [搜索 ⌘F]      [发现][详情][设置][扫描] │
├──────────┬───────────────────────────────────┬───────────────┤
│ sidebar  │ list-pane                          │ detail 332    │
│ 232      │ header 64 / chips / table          │ header 52     │
│          │                                    │ body scroll   │
│          │                                    │ footer 56     │
├──────────┴───────────────────────────────────┴───────────────┤
│ statusbar 44  [扫描状态]          [批次回执][已选摘要][清理]     │
└──────────────────────────────────────────────────────────────┘
```

- 默认窗口 1180×760（与 Wails 配置一致）；最小 920×560。
- 三栏之间用 1px 发丝线，不用间隙卡片；整个工作区是一张连续的桌面。
- 顶栏左侧品牌宽度与侧栏对齐（232px），形成一条竖向轴线。
- 侧栏 232px；详情 332px；列表自适应剩余宽度。
- 列表内部不是「卡片」：表头与行共享同一基线，选中行满宽着色。
- 详情面板内容可滚动，底部操作栏固定在面板底部。

### 断点

| 宽度 | 行为 |
|---|---|
| ≥ 1120 | 三栏完整 |
| 920–1119 | 详情默认收起，可通过按钮以浮层打开（盖在列表右侧） |
| ≤ 1000 | 侧栏收成 64px 图标栏（Agent 图标 + tooltip） |
| ≤ 980 | 表格隐藏「项目路径」列；≤ 900 隐藏「消息」列（窗口最小 920，实际只在原型缩小时触发） |

## 6. 组件

### 6.1 按钮

- **Primary（扫描）**：墨色实底 `--ink`，白字（深色模式反相），高 32，圆角 7，无阴影。
  按下 `translateY(1px)`；悬停亮度提升 6%。图标 15px，右侧 `<kbd>` 提示。
- **Secondary（发现/取消/在 Finder 中显示）**：透明底，1px `--line-strong`，文字 `--ink`。
- **Quiet（图标按钮）**：32×32，悬停 `--accent-tint`，按下缩放 0.97。
- **Danger（永久删除确认）**：`--danger` 实底白字，只在确认对话框出现。
- **Clean（状态栏清理）**：默认墨色实底，文案「清理 N 条」；永久删除模式下变危险色。
- 禁用：降不透明度到 45%，`cursor: not-allowed`，保留文案解释原因。

### 6.2 输入与搜索

- 顶部搜索为 34px 高的胶囊形（圆角 9，不是全圆），1px 发丝线，内嵌搜索图标。
- 聚焦时边框变 `--accent`，外加 3px `--accent-tint` 光晕；不移动布局。
- 右侧显示 `⌘F` 键帽；有内容时出现清除按钮。
- 键帽 `<kbd>`：11px mono，1px 边框，`--canvas-deep` 底，高 18px。

### 6.3 复选框

- 16px，圆角 4，1px `--line-strong`；选中为 `--accent` 底 + 白色对勾。
- 行悬停时复选框边框加深；键盘焦点环在复选框外 2px。
- 表头全选为三态（全选/部分/未选），部分选中用横线。

### 6.4 表格

- 表头 36px，`--surface` 同色底，11px `micro` 标签，底边 1px `--line`。
- 行：舒适 56px / 紧凑 42px；悬停底色 `--accent-tint` 的 45%；
  选中行底色 `--selection`，左侧 2px `--accent` 指示条（不改变行高）。
- 键盘焦点行：1px `--accent` 内描边 + 2px 外焦点环，与选中态可叠加。
- 列宽：勾选 40 / 标题自适应（最小 260）/ 项目 180 / 消息 64 / 体积 88 / 更新时间 96 / 悬停操作 36。
- 标题行：13.5px 590；摘要 12px `--ink-2`，单行截断。
- 数字右对齐，等宽数字；时间右对齐。
- 悬停时最右侧出现「⋯」菜单按钮；不改变其他列宽度。
- 空状态占满表格区域，不显示空表头。

### 6.5 Agent 行（侧栏）

- 44px 高，圆角 7，左右 8px 内边距。
- 图标 20px（品牌 SVG），名字 12.5px，右侧计数 11px mono；名字下方 10.5px 体积说明。
- 当前 Agent：`--accent-tint-strong` 底 + `--accent` 左侧 2px 指示条。
- 未安装/不可用 Agent：45% 不透明度，右侧「未安装」，hover 有 tooltip 解释。
- 分组标签 11px `micro`，上方间距 20px；分组计数靠右、`--ink-3`。

### 6.6 详情面板

自上而下：
1. 面板头 52px：「详情」+ 关闭按钮。
2. Agent 身份行：图标 28 + Agent 名 + 厂商；右侧存储类型徽标。
3. 会话标题（16px/22 600）+ 相对更新时间与消息数。
4. 状态徽标行：`可能正在使用`（警告）/ `文件` `SQLite 行` `目录`（中性）/ `自定义`。
5. 当前会话警告（如有）：警告底、1px 警告边、图标 + 两句解释。
6. 统计三格：体积 / 消息 / 最后更新（等宽数字，发丝线分隔）。
7. 「清理影响」：正文去向、索引处理、是否可撤销、真实释放（信任关键，放在路径之前，默认高度内可见）。
8. 「文件位置」：等宽路径，每行可复制/在 Finder 显示；SQLite 会话说明无独立文件。
9. Agent 说明：低视觉权重，引用样式，可展开。
10. 底部操作栏：`在 Finder 中显示`（次按钮）+ `选中此会话/取消选中`（主按钮）。

### 6.7 状态栏

- 44px，`--canvas-deep` 底，顶边 1px `--line`。
- 左侧：状态点 + 状态文字；扫描中显示 120px 进度条与 `12/30 · Cursor`；错误显示警告链接。
- 右侧：批次回执（可撤销）→ 已选摘要 → 清理按钮，间距 12px。
- 已选摘要用「已选 3 条 · 180 KB」；下一行小字「真实释放 0 B」在废纸篓模式必须出现。
- 无选择时清理按钮禁用，并显示「选择会话后可清理」的 tooltip。

### 6.8 空间账本（Space Ledger）

清理确认里的签名组件。用账本式三行解释空间去向，而不是一句「删除 3 条会话？」：

```
会话正文    180 KB   移入废纸篓 · 不释放
索引备份     已备份   保留在应用支持目录
真实释放      0 B    清空废纸篓后生效
```

- 行高 32，等宽数字右对齐，左侧标签 12px `--ink-2`。
- 底部 1px 分隔线；总计行 13px 590。
- 永久删除模式：第一行变 `--danger`，总计行显示真实释放量。
- 这是产品「诚实」的视觉化身，任何清理入口都应引用同一组数字。

### 6.9 抽屉（Sheet）

- 从右侧滑入，宽 420（设置）/ 640（发现），高度满窗口，圆角只在自由边。
- 标题 21px display，副标题 12px `--ink-2`；关闭按钮 28px。
- 内容 padding 24；分组标题 11px micro + 顶部 24 间距。
- 底部隐私声明固定在抽屉底部，12px `--ink-3`。
- 移动/窄窗口时变为全宽覆盖。

### 6.10 对话框

- 宽 560，居中，圆角 12，24px 内边距。
- 标题 21px；导语 13px；操作按钮右对齐，取消在左，确认在右。
- 破坏性确认按钮用危险色；只有永久删除时才要求勾选「我明白永久删除无法恢复」。
- 不嵌套滚动；内容超长时抽屉化。

### 6.11 通知（Toast）

- 底部居中，距状态栏 12px，最大宽 460，圆角 9，墨色底浅色字（深色模式反相）。
- 结构：图标 + 主文案 + 可选操作（撤销）+ 关闭。
- 6 秒自动消失；悬停暂停；最多同屏 3 条；出现/离开只做 8px 位移 + 淡入淡出。
- 成功不用感叹号；错误文案直接说明原因与下一步。

### 6.12 命令面板

- 顶部居中，宽 600，最大高 70vh，圆角 12，遮罩 + 模糊。
- 输入行 52px，无边框，占位「搜索会话或输入命令…」，右侧 `esc`。
- 结果按组：会话 / 动作 / Agent；组标题 10px micro。
- 每行 44px，左侧图标，右侧快捷键；选中行 `--accent-tint`，左侧 2px 指示条。
- 空结果：一句「没有匹配的命令」+ 建议；不显示插画。

### 6.13 菜单与浮层

- 筛选、快速选择、右键菜单统一 240–280 宽，圆角 9，阴影浮层，4px 内边距。
- 分组标题 10px micro；选项行 30px；快捷键靠右。
- 勾选型选项显示对勾，不出现在菜单外。
- 出现位置自动避让窗口边缘；点击外部/Esc 关闭。

## 7. 图标

- 一套 1.75px 描边的线性图标，24×24 viewBox，圆角端点与连接；在 15/16px 渲染。
- 语义固定：扫描=环形箭头、发现=星芒、详情=右栏、设置=齿轮、清理=垃圾桶、
  撤销=逆时针箭头、警告=三角、信息=圆、位置=文件夹、锁定=盾/锁、更多=三点。
- **Agent 图标是品牌资产**：内置 Agent 使用随二进制分发的官方矢量图；
  未知 Agent 先用系统 `.app` 图标，再回退到品牌色首字母。图标永远不空。
- 不用 emoji 充当图标；不用混合描边粗细。

## 8. 动效

| 场景 | 时长 | 曲线 | 属性 |
|---|---|---|---|
| 悬停/选中/键帽 | 120ms | `cubic-bezier(.2,.8,.2,1)` | background, color |
| 按钮按下 | 90ms | 同上 | transform: translateY(1px) |
| 行进入列表 | 180ms | 同上 | opacity + translateY(4px) |
| 详情内容切换 | 140ms | 同上 | opacity（不位移，避免跳动） |
| 抽屉 | 240ms | `cubic-bezier(.32,.72,0,1)` | translateX + opacity |
| 对话框/命令面板 | 180ms | `cubic-bezier(.2,.8,.2,1)` | opacity + scale(.985→1) |
| 通知 | 160ms | 同上 | opacity + translateY(8px) |
| 扫描进度 | 220ms | `cubic-bezier(.3,.8,.3,1)` | scaleX |
| 扫描脉冲 | 1.6s infinite | ease-in-out | opacity（仅状态点） |

- 只动画 `transform` / `opacity`；进度条用 `scaleX` 而不是 `width`。
- 列表中同时进入的动画最多 8 行、每行延迟 12ms；超过直接出现。
- `prefers-reduced-motion: reduce` 时：所有动画降到 0.01ms，禁用脉冲与错峰。
- 不自动播放循环动画（扫描中的状态点除外）。

## 9. 无障碍

- 正文/元信息对比度 ≥ 4.5:1；大字 ≥ 3:1；已在上表校准。
- 所有可交互元素有可见 `:focus-visible` 环：2px `--focus-ring`，offset 2px。
- 表格使用 `role="grid"` 语义（或 table + aria-selected）；行可 Tab 到达，
  ↑/↓ 移动焦点，空格切换选择，Enter 打开详情。
- 抽屉/对话框：焦点陷阱、Esc 关闭、关闭后焦点回到触发元素；`aria-modal="true"`。
- 扫描进度用 `role="progressbar"` + `aria-valuenow`；结果用 `aria-live="polite"`。
- 装饰性图标 `aria-hidden="true"`；图标按钮必须有 `aria-label`。
- 触控/点击目标最小 28×28（桌面），相邻目标间距 ≥ 8。
- 提供「跳到会话列表」跳过链接。
- 不依赖颜色单独传达状态：警告、选中、危险都有文字或图标。

## 10. 文案

语气：**平静、准确、可核对**。像一位把你文件当回事的同事。

- 用「清理」，不用「清扫/扫除/释放」等混合动词。
- 废纸篓模式必须出现「不释放」，释放量必须叫「真实释放」。
- 单位：`0 B`、`180 KB`、`1.5 MB`、`3.3 MB`；不写「约」除非真的是估算。
- 时间：行内「今天 19:32」「昨天 21:50」「周四 14:20」「9月12日」；
  详情内使用完整日期「2026年10月17日 19:32」。
- 不用感叹号；不用「Oops」「哎呀」；错误直接说原因与下一步。
- 按钮用动词 + 宾语：「扫描」「清理 3 条」「移入废纸篓」「撤销」「在 Finder 中显示」。
- 空状态给下一步，不给文艺句子：「这台 Mac 上还没有找到会话。扫描只会读取文件，不会修改。」

术语表：

| 用 | 不用 |
|---|---|
| Agent / 会话 / 清理 / 移入废纸篓 | AI 助手 / 对话 / 删除（当指废纸篓时） |
| 真实释放 / 未释放 | 释放空间（对废纸篓模式） |
| 索引 / 备份 / 撤销 / 批次 | 元数据 / 回滚 / 任务 |
| 发现 / 收录 / 适配器 | 扫描新 Agent / 添加（含糊时） |

---

## 11. 反模式（明确禁止）

- 禁止紫色/蓝色 AI 渐变、霓虹描边、发光按钮。
- 禁止纯黑 `#000000` 画布。
- 禁止把卡片、边框、阴影三层叠加成「卡片套卡片」。
- 禁止所有元素都是胶囊；胶囊只用于状态徽标。
- 禁止在数据表里使用大圆角卡片和悬浮阴影。
- 禁止装饰性动画、视差、无限循环光效。
- 禁止 emoji、网络字体、外部图片、Google Fonts。
- 禁止「Oops」、感叹号、AI 套话（Seamless / Elevate / Unleash / Next-Gen）。
- 禁止用颜色单独表达状态（必须配文字或图标）。
- 禁止把「移入废纸篓」描述成已释放空间。
